# Module 33 quiz: Class Actions and Public-Interest Litigation

This quiz has 10 scenario questions on the whole module: which claims may be brought as class actions, the registry, certification, settlements, objections and exits, remedies, the two funds, fees and awards, public-interest routes, and choosing between your own claim, a regulator complaint and a class action. Each question puts you in the position of a class member, a consumer, an organisation or a court and asks for the best lawful next step. The pass mark is 70%.

Take it after both practice labs and, ideally, the module project.
