# Module 28 quiz: Insolvency and Execution

This quiz has 10 scenario questions on the whole module: the execution file and the warning, enforcement measures and protected assets, the debtor's defences, payment orders and consolidation, individual insolvency from application to discharge, and corporate insolvency. Each question puts you in the position of a debtor, a creditor or an employee and asks for the best lawful next step. The pass mark is 70%.

Take it after both practice labs and, ideally, the module project.
