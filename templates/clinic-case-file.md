# Clinic case file (תיק עבודה לסכסוך: כרטיס תיק, כרונולוגיה, נספחים, יומן)

**What it is for:** the working file for one civil dispute of your own, from the first note to enforcement: a cover page, the parties, a dated chronology, an evidence index, the remedy calculation and a running case log. It is not filed with any court; you build your letters and your statement of claim from it. Used throughout module 12 (lessons 12.1–12.8) and the module 12 project.
**Who may use it:** you, for your own dispute. Running a file for another person as an occupation or for payment is reserved to lawyers (Bar Association Law 1961, s. 20).
**Where:** keep it in one folder (paper or cloud), with every exhibit saved as a PDF named by its number.
**Disclaimer:** act in your own name only. This is not legal advice — check current rules before you send or file anything.

Notes in English in brackets are guidance; delete them when you print the file for the hearing.
